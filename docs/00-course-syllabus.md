# 📖 第 1 课：开卷有益 —— 大模型两大娘胎硬伤与 RAG 极简闭环 (40 分钟)

> **本课目标**：看清大模型的知识边界，理解为什么微调和长上下文救不了动态业务，掌握 RAG 的解耦第一性原理，跑通最小 Naive RAG。

### 1. 惨案开场：选品经理硬问大模型，差点亏损 50 万！（00:00 - 10:00）
- **商业事故现场**：亚马逊美国站“极光出海”选品经理硬问大模型 2026 秋冬冲锋衣（SKU-JK902）选品调研；
- **大模型三大致命裸答**：
  1. 谎称“普通 DWR 防泼水可直接标 100% Waterproof 全防水且免检测” ➔ 引爆美国 FTC 虚假宣传罚单与封店；
  2. 谎称“美码男女版型通用 40 英寸” ➔ 忽略女款收腰与内长，引爆 40% 退货率；
  3. 谎称“14 天拆封不可退” ➔ 违反亚马逊 Q4 Holiday Extended Return 延长退货政策；
- **核心设问**：为什么大模型在严肃商业场景下如此不可靠？

### 2. 机制剖析：大模型两大生来无法克服的娘胎硬伤（10:00 - 20:00）
- **硬伤一：数据动态更新的时效盲区（Temporal Blindness）**
  - 权重参数在预训练结束时物理冰封；商业规则、季节更迭、法律法规每分每秒都在变；
- **硬伤二：垂直深度专业硬事实与精度的缺失（Lack of Precision Grounding）**
  - 缺乏 AATCC 127 15,000mm 静水压、40D/48F 230 GSM 经编、Inseam 矮版 28" 精确公差；
  - 面对专有数字与矩阵，大模型本质是在做 Next-Token Prediction 概率采样（一本正经瞎猜）；
- **为什么其他方案走不通？**
  - **全量微调（Fine-Tuning）**：上新快、成本极高、时效滞后、精密尺码灾难性遗忘；
  - **长上下文（Long-Context）**：Token 成本高昂、首字延迟 8~10 秒、Lost in the Middle 走神漏看。

### 3. 第一性原理：开卷考试与架构解耦（20:00 - 28:00）
- **解耦本质**：逻辑推理（大模型大脑）与 知识存储（外部检索系统）彻底分离；
- **向量几何空间的本质**：
  - 文本切片向量化（Embedding）与高维几何坐标映射；
  - 余弦相似度（Cosine Similarity）数学原理：$$\cos(	heta) = rac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\| \|\mathbf{v}\|}$$

### 4. 极简闭环：三步法跑通瑜伽裤基础选品（28:00 - 40:00）
- **离线建库流水线**：Document ➔ Chunking (512 tokens) ➔ Embedding ➔ Vector DB 索引；
- **在线翻书与生成**：Query ➔ 向量化 ➔ Cosine Top-K 近邻搜索 ➔ Prompt 注入 ➔ 大模型生成；
- **现场实操验证 Q1**：提问瑜伽裤（SKU-YG301）面料规格 ➔ 秒级命中 75% Nylon 66 + 25% Lycra，230 GSM，Squat-Proof 规范；
- **本课小结与悬念**：跑通 Demo 以为可以准时下班？下一课真实业务将迎来连环暴击！

# 📖 第 2 课：连环翻车 —— 稀疏货号匹配、深度重排与上下文装箱 (40 分钟)

> **本课目标**：直击纯向量检索的四大死穴，深入掌握 BM25 倒排索引、IDF 爆发机制、Cross-Encoder 面对面重排与 Context Repacking 装箱工程。

### 1. 翻车一：货号与专有面料搜不出来？ ➔ 逼出 BM25 + RRF 混合检索（00:00 - 12:00）
- **事故复盘**：搜索 `SKU-JK902`、`Cordura 500D`、`YKK 8#`，纯向量由于子词切分和高维平滑，核心切片被挤到第 40 名；
- **算法救场：BM25 稀疏倒排索引与 IDF 爆发**：

  - 专有编码全库唯一，IDF 分数核爆，一招秒杀置顶！
- **工业融合标准：RRF（Reciprocal Rank Fusion）**：
  $$RRF\_Score(d) = \sum_{m \in \{Dense, BM25\}} rac{1}{60 + rank_m(d)}$$

### 2. 翻车二：2023 作废旧表抢榜、男女版型串线？ ➔ 逼出 Cross-Encoder 重排（12:00 - 22:00）
- **事故复盘**：2023 废止偏小尺码表因词频密集抢占 Top-1，男款 40" 直筒串线推给女款；
- **机制剖析**：Bi-Encoder 双塔各自编码，缺乏 Token 交叉注意力，无法识别时效与修饰关系；
- **两步破局**：
  1. **Metadata 预过滤**：`status == 'Active' AND department == 'Women'` 物理阻断；
  2. **Cross-Encoder 深度重排**：Query 与 Doc 拼接送入 Transformer 做 Full Self-Attention 交叉打分。

### 3. 翻车三：买家问“遮肉”、选品搜“老钱风”？ ➔ 逼出 Query Rewrite（22:00 - 30:00）
- **事故复盘**：用户时尚口语与严肃工业质检参数之间的词汇鸿沟（Vocabulary Mismatch）；
- **算法解法**：基于轻量小模型的 **Query Rewrite 查询改写** 与 **Multi-Query 多路并发拓展**，将“老钱风开衫”自动拓展为“100% 澳大利亚美利奴羊毛 16 针高密精纺”。

### 4. 翻车四：跨页多维尺码表中间走神？ ➔ 逼出 Context Repacking 装箱（30:00 - 40:00）
- **事故复盘**：跨页大表中包含 Petite 28" / Regular 31" Inseam，塞在 Prompt 中间被大模型漏看；
- **Lost in the Middle 破局**：
  - **Reverse 反向升序排布**：最高分切片紧贴 Prompt 末尾的 Query；
  - **Adjacent Chunk Merging**：相邻碎片切片自动平滑缝合，XML 标签结构化包裹；
- **本课小结**：四大工程组合拳构建了检索与装箱的最强防线。

# 📖 第 4 课：泥泞战场 —— 工业级脏数据 Ingestion 治理与层次化父子索引 (40 分钟)

> **本课目标**：攻坚生产环境最痛苦的 Ingestion 脏数据治理七重山，掌握 Parent-Child 父子切片、句子窗口与 HNSW 向量索引调优。

### 1. 真实世界的暴击：Ingestion 脏数据七重山治理（00:00 - 15:00）
- **现实没有干净 Markdown**：供应商扫描件 PDF 质检单、乱序双栏、跨页大表与带错别字的买家 Review；
- **四大关键数据治理工程**：
  1. **MinerU / LayoutLM 版面分析**：按自然阅读顺序重组双栏文本，消除 OCR 字符粘连与乱码；
  2. **Table Header Injection（动态表头注入）**：跨页大表切片后，为每一行子切片动态拼装【尺码/胸围/腰围/Inseam】完整表头；
  3. **买家 Review 评论蒸馏**：用 LLM 剔除情绪化废话，提纯“偏小半码/略微透光”原子级知识；
  4. **PII 隐私脱敏**：买家身材信息与私人地址自动化掩码脱敏，符合 GDPR 合规。

### 2. 层次化切片工程：Parent-Child 父子切片与句子窗口（15:00 - 28:00）
- **传统分块的永恒矛盾**：
  - 小切片（128 tokens）：语义极其精准，但丢失上下文，大模型答非所问；
  - 大切片（1024 tokens）：上下文完整，但向量表示被泛化稀释，命中率暴跌；
- **破局方案 A：Parent-Child（Small-to-Big）父子切片架构**：
  - 索引端：对 128-token 的 Child Chunks 进行 Embedding 并存入向量库；
  - 检索端：命中 Child Chunk 后，自动映射回滚其所属的 1024-token Parent Chunk 喂给大模型！
- **破局方案 B：Sentence Window Retrieval（句子窗口回溯）**：
  - 单句精准向量命中 ➔ 动态扩展前后 $K$ 个句子窗口作为上下文装箱。

### 3. 生产级向量索引调优与高性能检索（28:00 - 40:00）
- **HNSW（分层可导航小世界）图索引深度调优**：
  - 核心参数机理：$M$（每个节点邻居数）、$efConstruction$（建图搜索深度）、$efSearch$（在线检索精度与 QPS 权衡）；
- **Product Quantization（PQ 乘积量化）与显存压缩**：
  - 768 维高维向量压缩 4~8 倍，实现千万级商品切片的百毫秒近邻检索；
- **语义缓存（Semantic Cache / GPTCache）**：
  - 历史高频提问向量余弦分 $\ge 0.95$ 时直接命中缓存，降低 40% LLM 调用成本；
- **本课小结**：打牢数据与索引地基，最后一课构建质量防线与模型进化。

# 📖 第 5 课：钢铁防线 —— 垂直领域微调、RAG Triad 评估与 100% 门禁 (40 分钟)

> **本课目标**：掌握 Embedding/Reranker 服饰垂直领域对比微调，建立 RAG Triad 形式化评测体系与 100% 事实忠实度 CI/CD 发布门禁飞轮。

### 1. 垂直领域微调：让模型真正听懂服饰黑话（00:00 - 12:00）
- **痛点**：开源通用模型不懂“小香风”、“老钱风”、“四面弹”、“Inseam 内长”；
- **对比学习微调（Domain Adaptation）**：
  - 从历史搜索与成交 PDP 构建正样本；
  - 基于 BM25 误召回构建 **Hard Negatives（高难负样本）**；
  - 使用 MultipleNegativesRankingLoss 微调 Embedding 与 Cross-Encoder，垂直指标提升 25%+。

### 2. 量化评估体系：RAG Triad 正交解耦（12:00 - 24:00）
- **拒绝凭感觉评估**：
  1. **Context Relevance（检索相关度）**：召回片段中有效信息密度，消除噪音；
  2. **Faithfulness（事实忠实度）**：**服饰出海第一死线！** 答案能否被证据严格逻辑证明；
  3. **Answer Relevance（答案契合度）**：是否直接命中用户提问；
- **NLI 形式化证明**：将大模型回答拆解为原子断言（Atomic Claims），逐一验证 Premise 蕴含关系。

### 3. CI/CD 自动化门禁与数据进化飞轮（24:00 - 34:00）
- **500 道服饰箱包 Gold Dataset 回归测试流水线**；
- **质量门禁红线**：Faithfulness 必须达到 100%，历史废弃版本零泄露，否则自动阻断代码与知识库发布；
- **线上可观测性（Observability）**：OpenTelemetry 全链路 Trace，抓取点踩与低置信度 Bad Case，清洗后回流训练集。

### 4. 总结升华：工业落地的四大核心军规（34:00 - 40:00）
- **军规一（问题驱动）**：不为炫技引入复杂组件，每个模块都有其特定的翻车场景；
- **军规二（组合降维）**：混合检索 + 重排 + Reverse 装箱即可解决 95% 生产问题；
- **军规三（数据地基）**：Garbage In, Garbage Out，脏数据治理决定 RAG 的上限；
- **军规四（评测底线）**：用确定性的工程体系约束概率大模型，守护商业生命线！
