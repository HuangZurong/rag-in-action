# 精品试讲终极复盘与主线护栏（防走偏对照表）

## 1. 目标校准（我们为什么能赢？）
- **核心定位**：一场 40 分钟的“工业级 AI 专家 RAG 试讲”。
- **听众认知**：市面上的“三板斧玩具 Demo”根本无法在生产环境存活；真正的 RAG 核心在**数据治理、混合检索与解耦评估**。
- **贯穿抓手**：Amazon 欧洲站跨境客服（德国站含锂电池商品退货）。

---

## 2. 40 分钟主线 vs 支线（强护栏）

| 模块 | 时间 | 现场必须做的事（主线） | 坚决不能做的事（防走偏） |
|---|---|---|---|
| **Phase 1: 破局** | 6 min | 抛出带电退货案例，讲清为什么不能全塞 Prompt / 不能微调，给出公式：$\text{Answer} = \text{LLM}(q, \text{Context})$。 | **禁**：扯过长历史、念大段论文定义。 |
| **Phase 2: 最小闭环** | 8 min | 快速梳理 DOC $\to$ Chunk $\to$ Embedding $\to$ Vector $\to$ LLM，展示 Q1（普通退货）跑通基线。 | **禁**：现场 live coding 写代码、现场 pip install。全部用现成封装结果展示。 |
| **Phase 3: 制造惨败** | 10 min | 输入主问题 Q2（带电退货），现场亮出 Top-3 检索结果：DOC-004（废止版）高分霸榜，模型输出违规回答。 | **禁**：只给听众看文字，必须把 DOC-004 的 0.89 分数和废止条款展示出来。 |
| **Phase 4: 精准优化** | 8 min | 加 Metadata 预过滤 + Cross-Encoder 重排，现场展示 DOC-001/002 夺回第一，输出合规答案；亮出“问题-技术”地图。 | **禁**：现场展开讲 GraphRAG / Agentic 内部实现；它们只作为“技术地图”在表里亮相。 |
| **Phase 5: 降维打击** | 8 min | 讲透 RAG Triad（检索相关 vs 事实忠实 vs 答案契合），展示 10 题自动化评测数据，收尾升华到数据治理与 CI/CD 门禁。 | **禁**：长篇大论讲具体工具部署细节，只讲方法论与业务价值。 |

---

## 3. 主线与高级货的“主从关系”

- **主线（必须现场跑通、有数据支撑的最小核心）**：
  $$\text{带电退货案例} \to \text{纯向量检索命中废止版失败} \to \text{Metadata+Rerank 修复} \to \text{RAG Triad 指标验证}$$
- **支线（作为专家全景视野，用表格/架构图预告，绝不展开）**：
  1. **脏数据治理**：扫描件 OCR / 表格解析 / PII 脱敏（说明真实数据不会这么干净）；
  2. **多模态 RAG**：退货标签图、电池鼓包照片（说明视觉检索必要性）；
  3. **专有名词**：UN3481 / SKU 编码（说明 Hybrid Search 必要性）；
  4. **Graph RAG / Agentic RAG**：跨文档全局关系与多步工具调用（说明何时需要进阶）。
