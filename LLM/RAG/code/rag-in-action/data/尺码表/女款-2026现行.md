## 3. 身材测量指南

### 3.1 如何量胸围 (Bust)

1. 穿薄内衣, 直立放松
2. 用软尺绕胸部最丰满处 (乳头水平线) 一圈
3. 软尺水平贴合, 不紧不松, 可插入一根手指为宜
4. 正常呼吸, 不刻意挺胸或含胸

### 3.2 如何量腰围 (Waist)

1. 直立放松, 找到腰部最细处 (通常在肚脐上方约 2 英寸)
2. 软尺水平绕一圈, 不紧不松
3. 测量时不要收腹

### 3.3 如何量臀围 (Hip)

1. 直立, 双脚并拢
2. 软尺绕臀部最丰满处 (通常在耻骨联合下方 8-9 英寸) 一圈
3. 确保软尺前后水平

## 4. 女款剪裁特征

### 4.1 版型说明

- 冲锋衣在腰部设有 1.5 英寸弧形立体收腰 (Hourglass Fit), 下摆设马蹄防风弧度
- 工装裤在臀部和大腿保留运动放量, 膝盖处立体拼接
- 与男款差异: 女款胸围放量更小, 腰线高 1.5 英寸, 袖长短 2-3 英寸

### 4.2 Petite / Regular / Tall 选择

| 版型 | 适用身高 | 裤内长 | 说明 |
| :---: | :--- | :---: | :--- |
| Petite | ≤ 5'4" (162cm) | 27.5"-28.5" | 矮版, 裤腿短, 避免堆叠过长 |
| Regular | 5'5"-5'8" (165-173cm) | 30.0"-31.5" | 标准版, 大多数买家选择 |
| Tall | ≥ 5'9" (175cm) | 32.5"-34.0" | 高个版, 裤腿加长, 避免偏短 |

### 4.3 搭配建议

- 女款冲锋衣: 选平时上衣尺码即可, 已考虑内搭抓绒的放量
- 女款工装裤: 如喜欢宽松可选大一码, 如喜欢合身选平时尺码
- 女款瑜伽裤: 选平时尺码, 弹性面料 25% 氨纶适配不同体型
