## 版型特征

- 剪裁特点: 修身窄肩, 未做男女性别分版
- 导致问题: 买家按美码标准选择, 实际收到亚洲版型, 胸围比标准美码小 3-5 英寸
- 退货率: 高达 38%, 主要原因为 "尺码偏小" 和 "版型与预期不符"
