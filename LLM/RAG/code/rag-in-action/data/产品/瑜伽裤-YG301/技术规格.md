## 1. 产品概述

裸感无痕高腰瑜伽裤，定位北美中高端女性运动市场。目标用户为25-40岁瑜伽、普拉提、健身女性，追求裸感穿戴体验与深蹲防透光。

核心卖点：75% Nylon 66 + 25% Lycra四面弹深蹲零透光；230 GSM双面微磨毛Butter-soft触感；四针六线拼缝无摩擦；加宽高腰收腹隐藏钥匙袋。

## 2. 面料规格

### 2.1 纤维成分

75% Nylon 66 (锦纶/超细聚酰胺) + 25% Lycra Spandex (莱卡四面弹氨纶)。纱线40D/48F双面精密经编，克重230 GSM (±5g)。

Nylon 66熔点265°C(高于Nylon 6的220°C)，密度1.14 g/cm³，回潮率4.5%，吸湿快干。40D/48F: 40旦尼尔粗细，48根长丝束，单丝0.83旦尼尔超细柔软。

### 2.2 面料结构

经编(Warp-knitted)双面布：面层平纹致密组织提供防透光基础；底层微毛圈组织经碳素磨毛处理提供Butter-soft触感。克重230 GSM，厚度0.45mm，透气率85 mm/s。

### 2.3 功能性能

| 指标 | 测试方法 | 标准 | 实测 |
| :--- | :--- | :--- | :--- |
| 防透光 | SGS Squat-Proof | 透光率≤5% | ≤2% (5级) |

## 3. 工艺细节

### 3.1 缝纫

| 部位 | 工艺 | 线材 | 特点 |
| :--- | :--- | :--- | :--- |
| 侧缝/后缝 | 四针六线Flatlock | 20D/3尼龙弹力线 | 无重叠布边平整无摩擦 |
| 腰头拼接 | 三针五线Coverstitch | 同上 | 弹性保持不勒腰 |
| 裆部补强 | 菱形贴片 | 同上 | 防camel toe加强张力 |

四针六线: 六根线同时穿线形成网状覆盖，缝边无凸起，运动中皮肤不摩擦，是高端运动裤核心工艺。

### 3.2 腰头设计

腰头宽度4.5英寸(11.4cm)加宽高腰，内嵌1.5英寸宽橡筋弹力35-40N不勒不松。隐藏钥匙袋100×60mm。前片双层叠压视觉收腹约1英寸。

### 3.3 裤脚

激光切割封边无缝裁切不卷边。七分Crop 22" Inseam + 九分Full 28" Inseam两个版本。

## 4. 后整理工艺

### 4.1 双面微磨毛

面层240#碳素磨毛辊轻磨，底层320#中度磨毛形成Butter-soft触感。磨毛后生物酶退浆去浮毛防起球。

### 4.2 染色

经轴染色Beam Dyeing 98°C常压，活性染料Reactive Dyes。色牢度: 耐洗4级、耐汗渍4-5级、耐光4级。主色Carbon Black (Pantone Black 6 C)。

### 4.3 功能整理

- 抗菌: 银离子抗菌剂抑菌率≥99% (AATCC 100)
- 防紫外线: UPF 50+ (AATCC 183)
- 亲水柔软: 有机硅柔软剂表面摩擦系数≤0.15
