## 1. 产品概述

SKU-CR502 是一款经典复古宽松落肩开衫，采用 100% 澳大利亚进口超细美利奴羊毛为原料，纤维细度 ≤ 19.5 微米，经德国 Stoll 电脑横机 16 针高密精纺成形。版型取自经典老钱风（Old Money）落肩宽松廓形，配天然牛角扣及 2×2 罗纹加固门襟。成品经丝光、防缩、防起球等多道后整理工艺，满足日常机洗不缩水、不起球的穿着要求。
