| 业务场景与挑战 | 核心瓶颈 | 针对性高级技术 |
|---|---|---|
| **多系统混合与多轮口语化省略**（问“退货率是多少”走 ChatBI，问“退货规则”走 RAG；多轮中常省略主语“那女款的呢？”） | 缺乏全局意图路由机制，纯向量检索直接崩盘；多轮指代缺失导致检索词杂音过大 | **Semantic Router（声明式极速向量路由，5~15ms + Margin防撞车）+ SLM 会话状态指代消解与重写** |
| **包含大量特定专有名词**（精准 SKU 型号 `XT-9000-PRO`、危险品代码 `UN3481`、报关 HS Code `8507.60`、物流单号） | 通用 Embedding 模型在预训练中没见过这些专用编码，会把编码拆碎成多个无意义子词（Subwords）进行向量化，导致向量空间中距离分散，严重丢失精确匹配能力 | **Hybrid Search（BM25 关键词精确索引 + Dense 稠密向量混合检索）+ 领域专用 Tokenizer / Custom Embedding 微调** |
| **跨格式图文混排**（PDF 版退货标签图示、商品故障开箱照、装箱危险品 UN 标贴） | 纯文本模型看不见图表结构，向量检索丢失视觉位置与图文对应关系 | **Multimodal RAG（多模态 RAG）**：LayoutLM/OCR 解析版面、ColPali 视觉向量检索、VLM（视觉大模型）统一图文理解 |
| **知识库规模极大**（百万级 SKU、全欧多站点全量政策、海量历史客诉工单） | 单层检索耗时过长、Top-K 噪声泛滥、全局跨品类总结时向量上下文被打碎 | **Hierarchical Index（分层索引）+ Graph RAG（图 RAG）**：路由树预剪枝 + 全局实体关系汇总 |
| **规则版本与生效范围混杂**（2023 废止版与 2026 当前版字面高度相似） | 向量模型无法理解“已废止/生效中”的逻辑排他性 | **Metadata Pre-filtering（元数据硬过滤）** |
| **检索片段落入注意力盲区或切片断裂**（检索到了高分切片，但 LLM 回答仍然漏掉关键依据或无法准确定位 Citation） | 大模型存在 **Lost in the Middle** 注意力黑洞；固定长度切块造成跨段落语义断裂 | **Context Repacking（Reverse 反向升序排布 + 相邻切片动态缝合 Chunk Merging + XML 结构化包裹）** |
| **复合多步售后业务**（查德国政策 $\to$ 查订单物流状态 $\to$ 调接口计算退运费） | 单次检索无法完成多阶段决策 | **Agentic RAG（智能体 RAG + 工具调用）** |
